## Qué nos ayudaría saber

1. ¿Cuál de A, B, C o D prefieres para dormir? ¿Y para el gancho?
2. En C: ¿algún sonido distrae, suena falso o molesta? (El gentío tiene que sonar a gente lejos sin que se entienda
   ninguna palabra).
3. ¿El nivel del ambiente bajo la voz está bien, alto o bajo?
